# Neue Wörter in Sätzen – Bauplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Neue Wörter der Lektionen 4–6 (`l01c`, `l02`, `l02a`) steigen eine Treppe aus Satz-Aufgaben hoch (Satz kennenlernen → Satz ins Deutsche → Satz hören → Lücke / Deutsch → Italienisch), mit von Hand geschriebenen Sätzen. Die Päckchen richten sich nach der Reihenfolge der Sätze.

**Architecture:** Daten in `saetze-a1.js` (`SAETZE`), Logik ohne Oberfläche in `saetze.js` (`Saetze`, in Node testbar), Anzeige in `app.js` als neue Aufgaben-Art `satz` in der vorhandenen Vokabel-Runde (`abfrage`). Stufe = `karte.kennen` (0…3), kein neues `FORMAT`. Lektionen ohne `SAETZE` bleiben unverändert.

**Tech Stack:** Plain JS (keine Module, `<script>`), Node `node:test` über `werkzeuge/test/laden.js`, Safari/iPhone PWA.

**Spec:** `docs/superpowers/specs/2026-11-16-saetze-design.md`

## Global Constraints

- Keine Kosten, keine Fremd-Bibliotheken/Schriften. Alles Deutsch, Code-Kommentare deutsch.
- Keine Module: `saetze.js` legt `const Saetze = (() => { … })()` an, `saetze-a1.js` `const SAETZE = { … }`.
- `index.html`: `<script src="saetze-a1.js">` und `<script src="saetze.js">` **vor** `lektionen.js`; `werkzeuge/test/laden.js` `STANDARD` genauso (vor `'lektionen.js'`), `'Saetze'` und `'SAETZE'` in `NAMEN`.
- `sw.js`: beide Dateien in `DATEIEN`, `VERSION` erhöhen.
- Wort-IDs (`wortId()`) unverändert; kein `FORMAT`-Wechsel.
- Lektion `l01b` nicht anfassen (Nicole steckt mittendrin).
- Farben nur über Variablen aus `style.css` (Gelb nie als Schrift auf Creme); hervorgehobenes Wort z. B. Unterstreichung in `--akzent-linie`.
- Keine Punkte/Serien/Belohnungen. Limo in der Aufgaben-Karte wie bei den anderen Runden-Aufgaben.
- **Commit nur, wenn Nicole es sagt** (CLAUDE.md) – darum keine Commit-Schritte pro Task; am Ende ein Commit nach ihrem OK.
- Tests: `node --test "werkzeuge/test/*.test.js"` muss am Ende grün sein; `node werkzeuge/lektionen-pruefen.js` und `node werkzeuge/saetze-pruefen.js` 0 Fehler.

## Review Focus

1. **Wort ohne zweiten Satz für dieselbe Stufe** (nur 3 Sätze, mehrfach falsch): Aufgabe kommt trotzdem wieder (dann mit schon gesehenem Satz), Runde hängt nicht. → Test in Task 2.
2. **Gerät ohne Sprachausgabe** (`Lesen.kannSprechen` false): Stufe 2 wird zu Stufe-1-Aufgabe, Wort kann trotzdem nach oben. → Test in Task 2.
3. **Weitermachen mitten in einer Satz-Aufgabe** (App schließen, öffnen): `Speicher.daten.laufend.schritte` enthält Satz-Aufgaben als reine Daten (Satz-Text, Kacheln) und wird korrekt wieder angezeigt. → Prüfung im Browser in Task 4.
4. **Wort hat schon eine Karte mit `kennen` ≥ 4 oder ohne `kennen`** (aus „kenne ich“/alter Lernstand): keine Treppe, Verhalten wie bisher; `kennen` wird nie über 4 gezählt. → Test in Task 2.
5. **Wortpaare** zählen höchstens bis `kennen` 1 für Satz-Wörter (sonst überspringt die Treppe Stufen). → Test in Task 2.

**Interfaces:**
- Produces: `SAETZE[lektionId] = [{ wort, saetze: [{ it, de, form?, formen? }] }]`
  - `wort`: exakt wie in `woerter` der Lektion; jedes Lektionswort genau einmal; Reihenfolge = Lern-Reihenfolge.
  - `form`: Schreibweise des Worts im Satz, wenn nicht wörtlich gleich (für Hervorheben und Lücke). Ohne `form` muss `wort` ohne Artikel im Satz stehen.
  - `formen`: `{ form: grundform }` für unregelmäßige Formen bekannter Wörter, die `kandidaten()` nicht erkennt (z. B. `{ bevo: 'bere' }`).
  - Erster Satz = Kennenlern-Satz (Wort aus dem Zusammenhang erschließbar).
- Produces: `pruefeSaetze(k) → { fehler: string[], hinweise: string[] }` (exportiert wie `pruefeLektionen`).

- [ ] **Step 2:** `node --test werkzeuge/test/saetze-daten.test.js` → FAIL (SAETZE fehlt).

Ein Wort `form` im Satz `it` (Wörter über `Lesen.stuecke`) ist bekannt, wenn: `GRUNDWOERTER[form]`, oder `lektionVon(form) < l.nr`, oder es ist ein Wort **dieser** Lektion, das in der `SAETZE`-Liste vor oder an der aktuellen Stelle steht, oder `formen[form]` bzw. ein Kandidat aus `Woerterbuch.kandidaten(form)` erfüllt eine dieser Regeln, oder Eigenname (Großbuchstabe, nicht am Satzanfang). Sonst Fehler mit Satz und Wort. Weitere Fehler: Lektionswort ohne Eintrag / doppelt / nicht in der Lektion; < 3 Sätze; `form` (bzw. `wort` ohne Artikel) steht nicht im Satz; leeres `de`.

### Task 2: Logik `saetze.js`, Reihenfolge der Lektion, Treppen-Zähler

**Files:**
- Create: `saetze.js`, `werkzeuge/test/saetze.test.js`
- Modify: `lektionen.js:24-26` (`alle()`), `vokabeln.js:77-86` (`kennenGelernt`), `wiederholung.js:117-122` (`schluessel`)

**Interfaces:**
- Consumes: `SAETZE` (Task 1), `Vokabeln.wort`, `Vokabeln.istJung`, `Speicher.daten.karten`, `Lesen.kannSprechen`, `Wiederholung.heuteGeloest`, `Uebungen.kacheln(satz, vorrat)`.
- Produces (in `saetze.js`):
  - `Saetze.reihenfolge(lektionId) → string[] | null` – `wort`-Liste aus `SAETZE`, sonst `null`.
  - `Saetze.hat(wortId) → boolean` – Wort hat Sätze.
  - `Saetze.stufe(wortId) → 0|1|2|3|null` – `karte.kennen` für junge Karten, 0 ohne Karte, `null` wenn nicht jung (fertig/alt).
  - `Saetze.aufgabe(wortId, stufe, optionen = {}) → Aufgabe` mit Aufgabe = `{ art: 'satz', id, stufe, modus, satz: { it, de, form }, kacheln: string[], ohneWertung? }`. `modus`: Stufe 0 `'kennen'`, 1 `'de'`, 2 `'hoeren'` (ohne Sprachausgabe `'de'`), 3 abwechselnd `'luecke'` / `'it'` (nach Anzahl Aufgaben dieses Worts, nicht Zufall, damit testbar: gerade = `'luecke'`). `kacheln`: bei `'kennen'`/`'de'` deutsche Wörter des Satzes + 2 falsche aus anderen deutschen Sätzen; bei `'hoeren'`/`'it'` `Uebungen.kacheln(satz.it, vorrat)` mit `vorrat` = Sätze aus `SAETZE` bis zu dieser Lektion; bei `'luecke'` leer. `optionen.ohneWertung` wird übernommen.
  - Satzwahl: Stufe 0 immer erster Satz; sonst ein Satz des Worts, der nicht heute gelöst ist (`Wiederholung.heuteGeloest({ art: 'satz', satz })`) und nicht der zuletzt gezeigte dieses Worts (Merker nur im Speicher, nicht gespeichert); gibt es keinen, irgendeiner außer dem ersten.
  - `Saetze.hinweis(aufgabe) → string` – für `'luecke'`: Grundform bei Verben (Wort endet auf -are/-ere/-ire), sonst `Vokabeln.wort(id).de` (Kurzform ohne Klammern); Satz mit `___` statt `form`.
  - `Saetze.pruefe(aufgabe, antwort) → boolean` – `'kennen'`/`'de'`: gelegte Kacheln = `satz.de` ohne Satzzeichen, Groß/klein egal; `'hoeren'`/`'it'`: `Uebungen.pruefeKacheln`; `'luecke'`: wie `Vokabeln.pruefe` gegen `form` (Tippfehler-Nachsicht wie dort).
  - `Saetze.aufgabenFuerJunge(ids, { maxStufen }) → Aufgabe[]` – für jedes junge Wort mit Sätzen die Aufgaben ab seiner Stufe, höchstens `maxStufen` Stufen (Neue Wörter: 2, sonst 1).
- `lektionen.js` `alle()`: `woerter: Saetze.reihenfolge(l.id) || l.woerter` (Menge gleich, nur Reihenfolge).
- `Vokabeln.kennenGelernt(id, hoechstens = KENNEN_FERTIG)` – erhöht nur, wenn `kennen < hoechstens`.
- `Wiederholung.schluessel`: `if (a.art === 'satz') return 's:' + a.satz.it;` (vor den anderen Zeilen).

- [ ] **Step 1: Tests schreiben** `saetze.test.js` (eigene kleine Test-Daten über `laden(..., extraCode)` nicht nötig – echte `SAETZE.l01c` reichen):
  - `Lektionen.alle().find(l01c).wortIds` hat dieselbe Menge wie vorher, Reihenfolge = `SAETZE.l01c`.
  - Ohne Karte: `stufe` = 0, `aufgabe(id, 0).modus === 'kennen'` und `satz.it === SAETZE…saetze[0].it`.
  - Karte `kennen: 2`, `Lesen.kannSprechen = false` → `aufgabe(id, 2).modus === 'de'` (Review Focus 2).
  - Karte `kennen: 4` oder ohne `kennen` → `stufe` = `null`, `aufgabenFuerJunge` liefert nichts (Review Focus 4).
  - Zweimal `aufgabe(id, 1)` → zwei verschiedene Sätze; nach Markieren aller Sätze als heute gelöst kommt trotzdem eine Aufgabe (Review Focus 1).
  - `pruefe` für `'de'` mit richtigen Kacheln in anderer Groß-/Kleinschreibung → true; mit falscher Reihenfolge → false.
  - `kennenGelernt(id, 1)` bei `kennen: 1` ändert nichts (Review Focus 5); `kennenGelernt(id)` bei `kennen: 3` → Fach 1, fällig morgen (wie bisher).
  - `aufgabenFuerJunge([id], { maxStufen: 2 })` ohne Karte → Modi `['kennen', 'de']`.
- [ ] **Step 2:** `node --test werkzeuge/test/saetze.test.js` → FAIL.

### Task 3: Satz-Aufgaben in die Runden einbauen

**Files:**

**Interfaces:**
- Consumes: `Saetze.aufgabenFuerJunge`, `Saetze.aufgabe`, `Saetze.hat`, `Saetze.stufe` (Task 2).
- Produces: Runden-Schritte der Art `satz` in `abfrage.schritte` (Anzeige in Task 4).

- [ ] **Step 1: `wegRundenSchritte`**
  - `woerter`: Wörter mit Sätzen: `neu`-Schritt entfällt, stattdessen `Saetze.aufgabenFuerJunge(neuMitSaetzen, { maxStufen: 2 })` – geordnet: erst alle Stufe-0-Aufgaben, dann Wortpaare des Päckchens (wie bisher), dann die Stufe-1-Aufgaben gemischt. Wörter ohne Sätze wie bisher.
  - `ueben`: junge Wörter mit Sätzen → `aufgabenFuerJunge(ids, { maxStufen: 1 })` statt `waehlen`; nicht mehr junge Wörter der Lektion mit Sätzen → `Saetze.aufgabe(id, 1 + (i % 3), { ohneWertung: true })` statt `deutsch` (Stufe 1–3 reihum); Obergrenze bleibt 7 + 3 alte Wörter (`alteWoerter` unverändert).
- [ ] **Step 2: `starteRunde`** Standard-Runde (`r.jung`/`r.neu`): Wörter mit Sätzen wie in Step 1 (`neu` → maxStufen 2, `jung` → 1); Zweig `optionen.ids` („Wörter üben“ einer erledigten Lektion): Wörter mit Sätzen → `Saetze.aufgabe(id, 1 + zufällig 0…2, { ohneWertung: true })` statt `deutsch`/`frage`.
- [ ] **Step 3: Wortpaare** (~983): für Wörter mit Sätzen `Vokabeln.kennenGelernt(id, 1)` statt ohne Grenze.
